# Math.one — Mathematics 1

موقع مذاكرة تفاعلي باللغة العربية لموضوعات أول خمس محاضرات في Mathematics 1. المشروع يستخدم HTML وCSS وJavaScript فقط، ولا يحتاج تثبيت حزم.

## التشغيل
افتحي `index.html` في المتصفح مباشرة. ويمكن في VS Code تثبيت إضافة Live Server ثم الضغط بزر الفأرة الأيمن على `index.html` واختيار **Open with Live Server**.

## الأدوات
- **المحاضرة 1:** تركيب دالتين، عكس الدوال الخطية والقوى على الفرع الرئيسي، شروط المجال، تقدير عددي للمدى على فترة، وفحص إرشادي للزوجية أو الفردية.
- **المحاضرة 2:** تقريب النهايات من جهة واحدة أو جهتين وعند ±∞، وفحص عددي للاستمرارية ونوع الانقطاع المحتمل.
- **المحاضرة 3:** حساب الدوال المثلثية ومقلوباتها، والأسية، واللوغاريتم الطبيعي، والهايبر بولك.
- **المحاضرة 4:** حساب الدوال المثلثية العكسية والهايبر بولك العكسية، وعكس الدوال الأسية واللوغاريتمية.
- **المحاضرة 5:** اشتقاق تعبيرات تشمل الجمع والطرح والضرب والقسمة والأسس والدوال المثلثية والأسية واللوغاريتمية والهايبر بولك، بما فيها قاعدة السلسلة.

اكتبي التعبيرات باستخدام `x`, الأقواس، `+ - * / ^`، والدوال مثل `sin(x)`, `ln(x)`, `sqrt(x)`. اشتقاق الدوال رمزي، أما تقدير النهايات والاستمرارية والمدى على فترة وفحص التماثل فعددي وإرشادي. الأداة تعرض شروط المجال وتتحقق من قيمة `x` واحدة؛ والنتائج العددية ليست برهانًا رمزيًا، خصوصًا عند القيم الحدية أو النقاط الشاذة.

ملفات المقرر الأصلية أُرفقت منفصلة ولم تُنسخ إلى المستودع.

## النشر على GitHub Pages
من GitHub افتحي المستودع، ثم **Settings → Pages**. اختاري النشر من الفرع `main` والمجلد `/ (root)` ثم احفظي. بعد ظهور رابط الموقع يمكنك مشاركته.
